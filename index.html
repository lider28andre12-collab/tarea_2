Red

Conjunto de equipos que comparten información.

Router

Elige el camino entre distintas redes.

IP

Dirección lógica que ubica un dispositivo.

MAC

Módulo 03 / Investigación

La evidencia deja señales

La informática forense observa datos volátiles y persistentes para construir una explicación verificable de los hechos.

Evidencia digital

Dato que puede ayudar a explicar un hecho.

RAM

Memoria temporal que se pierde al apagar.

Log

Registro de acciones y eventos del sistema.

Tráfico

Datos que viajan entre dispositivos.

Dos significados de “registro”

Un registro de CPU es una celda ultrarrápida para operar. Un registro o log forense es una huella de eventos del sistema. Comparten nombre, no función.
